The 3 Claude skills worth installing.

Everyone’s telling you to install Claude skills. You only need three to cover about 80% of what you’ll use them for — one for video, one for design and one for writing. Here are the links, what each one does, and exactly how to install them.

The short answer

Install Video Shotcraft to build cinematic product launch videos, Apple Design to make your designs clean and minimal, and Humanizer to strip the signs of AI writing from anything you write. A Claude skill is a saved set of instructions Claude uses automatically when a task matches — install these three once and they work in the background from then on.

01

Video Shotcraft

Point it at your product. Get a cinematic launch video, built in code.

By Vincent WeiVideoClaude Code

What it does. You give it your product — a website, an app, a feature — and it plans and builds a full launch video: camera moves, transitions, title cards and sound effects, all written as code and rendered to an MP4. It has around 200 visual styles to pick from, so the result looks directed rather than templated.

Why it matters. A short, polished product video used to mean an agency or a motion designer. Now it’s a prompt and a few minutes of rendering — and because it’s code, you can ask for changes in plain English and render again.

Good for: product and feature launches, website hero videos, social clips and sales demos.

Worth knowing: it renders video, so it runs in Claude Code with Node.js and ffmpeg installed — not the plain chat app.

Prompts to try

Use video-shotcraft to make a 30-second launch video for [your website]. Keep it clean and minimal.
Turn our new [feature] into a 15-second vertical clip for Instagram, with title cards and a whoosh on each transition.

Install · Claude Code

npx skills add Vincentwei1021/video-shotcraft

Then restart Claude Code. Needs Node.js and ffmpeg on your computer.

DesignClaude appClaude Code

What it does. It gives Claude over 50 of Apple’s design principles from the Human Interface Guidelines. Whenever Claude designs or reviews something — a web page, an app screen, a slide, a social graphic — it follows the same rules on hierarchy, spacing, typography and restraint that make Apple’s products look the way they do.

Why it matters. Ask AI to design something and it tends to add more: more colours, more buttons, more badges. This skill flips the default to less, so the first draft already looks clean and minimal instead of needing three rounds of “simplify it”.

Good for: landing pages, app screens, slide decks, proposals, dashboards and design reviews.

Prompts to try

03

Humanizer

The one Dylan runs on every single piece of work he does with AI.

WritingClaude appClaude Code

What it does. It strips every sign of AI slop from your writing. It’s built on Wikipedia’s guide to identifying AI-generated text — the patterns editors use to spot machine-written articles — so it removes exactly the things readers notice.

Why it matters. People can tell. An email that opens with “In today’s fast-paced world” gets skimmed; a proposal full of “game-changers” loses trust. Humanizer keeps what you meant and drops the tells, so your work stops sounding like ChatGPT.

Good for: emails, proposals, LinkedIn posts, website copy, reports — anything a person will read.

Worth knowing: it’s about reading well, not beating AI detectors. Still read it back before you send.

Prompts to try

Humanize this email before I send it. Keep it short and keep my meaning.
Run the humanizer on this proposal and list the AI patterns you removed.

Install guide

Install them in five minutes.

Every skill is a folder with a SKILL.md file inside. Pick the way you use Claude — you only need one of these.

In the Claude app

claude.ai or the desktop app · no coding needed · Apple Design and Humanizer

  1. Download the skill. On its GitHub page, click the green Code button, then Download ZIP.
  2. Turn on code execution. Go to Settings › Capabilities and switch it on — skills need it.
  3. Upload it. Under Skills choose Upload skill and pick the ZIP.
  4. Use it. Start a new chat and ask for the task. Claude picks the skill up when your request matches — or ask for it by name.

In Claude Code

All three skills · paste into your terminal, then restart Claude Code

  Terminal
# 1 · Video Shotcraft (needs Node.js + ffmpeg)
$ npx skills add Vincentwei1021/video-shotcraft

# 2 · Apple Design
$ npx skills add https://github.com/dickwu/apple-design-skill --skill apple-design

# 3 · Humanizer
$ git clone https://github.com/blader/humanizer.git ~/.claude/skills/humanizer

Prefer to do it by hand? Copy each skill’s folder into ~/.claude/skills/ and restart.

Frequently asked questions

What are the best Claude skills to install?
Dylan Bailey’s pick is three: Video Shotcraft, for building cinematic product launch videos from code; Apple Design, which gives Claude Apple’s design principles so your designs come out clean and minimal; and Humanizer, which strips the tell-tale signs of AI writing from your text. Between them they cover video, design and writing, which is about 80% of what most people use Claude to produce.
How do you install a Claude skill in the Claude app?
Download the skill from GitHub as a ZIP (the green Code button, then Download ZIP). In Claude, open Settings, then Capabilities, make sure code execution is turned on, and upload the ZIP under Skills. The skill then appears in your list and Claude uses it when a task matches.
How do you install a Claude skill in Claude Code?
Run npx skills add followed by the skill’s GitHub owner and repository name, for example npx skills add Vincentwei1021/video-shotcraft. Or clone the skill’s folder into ~/.claude/skills/ yourself. Restart Claude Code and the skill is available.
Do I need Claude Code for these skills?
Only for Video Shotcraft, which renders video in code and needs Node.js and ffmpeg on your computer. Apple Design and Humanizer work in the regular Claude app as well as in Claude Code.
How do I use a skill once it is installed?
You don’t need to switch it on. Claude reads each skill’s description and uses it when your request matches. You can also ask for it by name, for example ’use the humanizer on this email’ or ’use video-shotcraft to make a launch video for our product’.
Are third-party Claude skills safe to install?
Treat a skill like any software you add to your computer. Only install skills from sources you trust, read the SKILL.md file first so you know what it tells Claude to do, and check whether it includes scripts. In a business, agree which skills staff can install before they start adding their own.
