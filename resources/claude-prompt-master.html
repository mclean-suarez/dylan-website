Prompt Master: one button that turns lazy prompts into great ones

The exact prompt from the video, plus a step-by-step guide to set it up in Claude in about 30 seconds.

By Beau Robards, Certified Claude Expert
Published 16 November 2026 · 5 min read
The short answer

Prompt Master is a free mod that adds a button above your prompt box in Claude Code. Type a rough prompt, press the button, and it asks you anything it’s unsure about, then rewrites your prompt in a proven structure. You read it and press Enter. To set it up, paste one prompt into a new Code chat.

What you need

  • The Claude desktop app (Mac or Windows), updated to the latest version. You’ll use its Code tab.
  • A paid Claude plan (Pro or above). Claude Code comes with paid plans. The mod itself is free.
  • No coding. You paste a prompt in plain English and Claude builds the mod for you.

1. Set it up in 30 seconds

  1. Open Claude and go to Code. Click the Code tab at the top of the desktop app.
  2. Start a new chat. Pick any folder when it asks. Your Documents folder is fine.
  3. Paste the prompt below and press Enter. Claude writes the mod, checks it and switches it on.
  4. Click “Turn them on” if Claude asks whether to turn on the mods it writes. Approve any steps it asks about.
  5. Look above your prompt box. A few seconds later, the Prompt Master button shows up.
prompt-master-setup.txt
Build me a Claude Code mod called "Prompt Master". I'm not a developer, so do all the work and keep it simple.

What it should do:

1. Add a "Prompt Master" button in the row just above my prompt box, in the desktop app and in the terminal. Also add a /prompt-master command that does the same thing.

2. When I press it, read whatever I've typed in the prompt box. If the box is empty, show a short message: "Type a prompt first, then press Prompt Master."

3. If anything important is missing or unclear (who it's for, what I want back, the tone or the length), ask me up to 3 short questions first, with suggested answers I can pick from. If my prompt is already clear, skip the questions.

4. Rewrite my prompt using this structure, leaving out any part that doesn't apply:
- Role: who Claude should act as
- Context: the background, and who the result is for
- Task: exactly what to produce
- Inputs: anything I gave, kept word for word
- Constraints: rules, length, tone and things to avoid
- Format: how the answer should be laid out
- Check: what a great answer must get right
Keep my intent and every fact I gave. Never invent facts, names, prices or dates. Use placeholders in square brackets for anything I still need to fill in. Plain English, no jargon.

5. Put the improved prompt back in my prompt box, replacing my draft, so I can read it, edit it and press Enter myself. Never send anything on its own.

6. While it works, show "Prompt Master is improving your prompt..." in the status line.

When it's built, check it loads with no errors. Then install it so it's on in every new Claude Code session, not just this chat. Finish by telling me, in two short lines, how to use it and how to turn it off.

Tip: Claude may ask to run a few commands while it builds and installs the mod. That’s normal. Read what each one says and click Allow.

2. Use it

Type what you want the way you’d say it, then press Prompt Master instead of Enter.

If something important is missing, it asks first. Tap an answer or type your own.

Then it puts the rewritten prompt back in your box. Fill in anything in square brackets, check it, and press Enter.

3. What it does to your prompt

You typed

write a post about our sale

prompt-master-output.txt
Role: Act as the social media manager for [business name], a [type of business] in [suburb].

Context: We're running a sale for our existing customers. [What's on sale, the discount and the end date.]

Task: Write one Instagram post announcing the sale.

Constraints: Under 120 words. Friendly and upbeat, Australian spelling, no more than 2 emojis. Don't make up prices or dates.

Format: A one-line hook, 2 to 3 short lines on the offer, a clear call to action, then 5 relevant hashtags.

Check: The offer and the end date are clear in the first two lines.

The structure is the same one we teach in how to write an AI prompt, with a few extra parts that make the first answer land closer.

4. Change it or turn it off

You change a mod the same way you made it: ask Claude in a Code chat. Copy one of these.

add-my-business.txt
Update my Prompt Master mod so every rewrite knows about my business: [business name], a [type of business] in [location]. Our customers are [who they are] and our tone is [friendly, professional, cheeky]. Only add this context when it's relevant to the prompt.
skip-questions.txt
Update my Prompt Master mod so it never asks questions. Rewrite straight away and use placeholders in square brackets for anything that's missing.
turn-off.txt
Turn off my Prompt Master mod so the button no longer shows. Don't delete it, so I can turn it back on later.
fix-the-button.txt
My Prompt Master button isn't showing above the prompt box. Check whether the mod is installed and turned on, fix whatever is stopping it, and tell me in plain English what was wrong.

Good to know: mods aren’t sandboxed. They can do anything Claude Code can do on your computer. Only add mods from prompts or people you trust, and if you’re unsure, ask Claude to explain what a mod does before you turn it on.

FAQs

Is Prompt Master really free?
The mod is free. You need a paid Claude plan (Pro or above) to use Claude Code, and each rewrite uses a small amount of your plan's usage.
Does it work in the normal Claude chat or on my phone?
No. Mods run in Claude Code: the Code tab of the Claude desktop app and the terminal. They don't show up in the regular chat or the mobile app.
Will it send my prompt without me seeing it?
No. It puts the improved prompt back in your prompt box. You read it, edit it if you like, and press Enter yourself.
What are Claude mods?
Mods are small add-ons that change how Claude Code works, such as adding a button, a panel or a step that runs before your prompt goes to the model. Anthropic launched them on 1 October 2026. You can ask Claude to build one for you in plain English.
Is it safe to add a mod?
Mods aren't sandboxed, so they can do anything Claude Code can do on your computer. Only add mods from people you trust. You can ask Claude to explain what a mod does before you turn it on.
The button didn't show up. What do I do?
Update the desktop app, check you clicked Turn them on when Claude asked, then start a new Code chat. Still missing? Paste the fix-the-button prompt from this guide and Claude will check and fix it.
